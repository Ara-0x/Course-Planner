## Task 12 — Keystore & secrets hygiene

**Finding.** `debug.keystore.base64` was committed; `app/build.gradle.kts`
hardcoded `android/android` debug passwords and an unconditional release
signing config with a repo-relative fallback path.

**Change.**
- `debug.keystore.base64` removed from git; `*.jks`, `*.keystore`,
  `*.base64` added to `.gitignore`.
- Non-secret values (store path, alias) moved to `gradle.properties`;
  passwords come **only** from environment / `-P` properties (no defaults,
  no committed file). Debug builds use the standard auto-generated debug
  keystore; release signing applies only when credentials are present
  (otherwise `assembleRelease` yields an unsigned APK, by design).
- CI side of the same rule: released APKs are debug-signed, so their keystore
  must keep a stable signature. CI restores it from the **`DEBUG_KEYSTORE_BASE64`
  repository secret** (never from git) and only falls back to a generated key
  with a loud `::warning::` — a changed signature would make installed APKs
  uninstallable as updates. Setting the secret is a documented one-time
  maintainer step (README «امضای بیلد و CI»).
- Honest caveat: the old key still exists in **git history** (removing the
  file from HEAD does not purge it). Rotating would break the upgrade path of
  installed builds, so it is recorded as a maintainer decision / follow-up
  instead of being forced here.
- Added the missing Gradle wrapper (`gradlew`, `gradlew.bat`,
  `gradle/wrapper/gradle-wrapper.jar`) so any machine builds with the
  pinned Gradle 9.3.1 reproducibly; the already-tracked
  `gradle-wrapper.properties` was regenerated byte-identical.

## Task 13 — CI version regression gate

`build-apk.yml` now:
1. runs `testDebugUnitTest` before assembling (tests gate the APK);
2. derives expected `versionCode`/`versionName` from `app/build.gradle.kts`
   instead of hardcoding them;
3. on `v*` tags, fails the release when `versionName != tag` or when
   `versionCode` is not strictly greater than the previous tag's code —
   a release can no longer ship with an unchanged version.
